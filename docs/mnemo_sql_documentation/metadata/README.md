# Metadata and Introspection

Commands to inspect catalog state, schema, and query plans.

## Overview

| Command | Purpose |
|---------|---------|
| `SHOW …` | List objects or status |
| `DESCRIBE` / `DESC` | Object schema and properties |
| `EXPLAIN` | Logical/physical plan for a query |
| `USE` | Set current database |
